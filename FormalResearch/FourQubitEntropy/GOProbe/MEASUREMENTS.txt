GO certificate: build measurements (Lean 4.34.0, 4 cores / 16 GB shared with other agents; times include
waiting for the shared lock in some rows, so they are upper bounds)

  GOConst.lean 2.3 MB     elaboration 28 s, 1.5 GB
  GOData_0..12 (13 parts, <= 1.8 MB each)   11-62 s each, peak 2.0 GB (GOData_7)

  330 s wall, RSS 7.5 GB (the RSS is dominated by the memory-mapped `import Mathlib`; the checker's own data and

  Phase profile of the same functions (standalone `#eval`, total 2 min 34 s for the first four lines):
    base part of U (0.73 M basis-atom products, 4.5 M Gamma*M products)   127 s
    correction part of U                                                    8 s
    one coordinate map actSP on U (134,574 terms: 1.5 s sort + 6.9 s key transform)   8.4 s   (6 permutations)
    sign changes flipSP (48 per full check, keys unchanged, no sort)
  Negative regression (one-off module, not committed because the repository allows `native_decide` only in
  Check.lean): the same `check` with the first coefficient of `lit` increased by 1 evaluates to `false`
  (`check cons perms flips badLit ... allBlocks = false` by `native_decide`, 325 s).
  `Smoke.lean` (toy certificate, kernel `decide +kernel`) builds in 7 s.
